# License Review Policy

A public GitHub repository does not automatically mean every included model, weight, dataset or extension is cleared for any use.

Review and record separately:
1. Repository/code license and exact commit.
2. Model-weight license and exact revision.
3. Dataset/provenance terms where available.
4. Custom nodes, extensions, plugins and transitive dependencies.
5. Restrictions for personal use, commercial use, redistribution and hosted services.
6. Attribution, notices, source-distribution and share-alike obligations.
7. SHA-256 hashes and artifact download source.
8. Approval decision, reviewer and review date.

Rules:
- Do not enable models with non-commercial or research-only restrictions in commercial workflows without written permission.
- Do not assume code license governs model weights.
- Do not assume a custom node shares the core application's license.
- FFmpeg obligations depend on build configuration and linked libraries.
- Face/voice cloning requires rights and consent checks.
- Preserve third-party notices.

The project-level license for this repository is intentionally unselected. The repository is public, but public visibility does not itself grant permission to reuse project code.
